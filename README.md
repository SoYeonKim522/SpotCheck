# SpotCheck

Find a free study seat on the UTS campus in real time

## What it does

- Browse buildings and levels, each showing how many seats are free right now
- Pick a seat by what you need — power outlet, window, partition, computer, quiet zone
- Hold the seat for 1 hour, extend up to 3 hours, or release it early
- A hold that expires frees the seat for everyone else
